# Fashion Website

Fashion Website là một dự án web bán hàng cho local brand thời trang, xây dựng bằng Django và Django Templates.

Mục tiêu của dự án là tạo một storefront đơn giản, dễ mở rộng và phù hợp cho các chức năng thương mại điện tử cơ bản như:
- hiển thị sản phẩm theo danh mục
- xem chi tiết sản phẩm
- thêm vào giỏ hàng và thanh toán
- đăng nhập, đăng ký và theo dõi đơn hàng
- quản trị dữ liệu và đơn hàng từ phía admin

## Công nghệ sử dụng

- Backend: Python, Django
- Frontend: HTML, CSS, JavaScript, Django Templates
- Database: SQLite

## Thành phần chính

- `backend/`: mã nguồn Django, models, views, urls và logic nghiệp vụ
- `frontend/`: templates, CSS và JavaScript giao diện
- `database/`: dữ liệu mẫu và file phục vụ seed dữ liệu

## Trạng thái dự án

Dự án đang được tổ chức theo hướng local development, phù hợp để học tập, demo tính năng hoặc tiếp tục mở rộng thành website bán hàng hoàn chỉnh.
